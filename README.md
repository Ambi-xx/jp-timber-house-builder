# JP Timber House Builder

Blender 5.0 add-on for parameterized Japanese timber-house massing.

## Current version

v0.4.0

Implemented:

- Metric millimeter-based parameters
- Two-story shell
- Floor slabs
- Single-slope roof mesh
- Roof overhang, thickness, and slope controls
- Organized Blender collections
- Rebuild and clear operations

Not yet implemented:

- Accurate plan-specific interior walls
- Doors and windows
- Stair geometry
- Wall tops trimmed to roof plane
- Timber framing

## Install

1. Zip the `jp_timber_house_builder` folder, or use the release ZIP.
2. In Blender: Edit > Preferences > Add-ons > Install from Disk.
3. Enable **JP Timber House Builder**.
4. In the 3D View, press `N` and open the **JP House** tab.
